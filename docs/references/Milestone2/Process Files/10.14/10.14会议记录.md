# 10月14日会议记录

**时间：** 10月14日 22：00 - 22：24

**会议主题：** Milestone 2 材料确认、代码开发协作及后续例会安排

**参与成员：** 全体成员——吴宇轩、刘星宇、杨林涛、郭柏村、**常珂舒** 

本次会议主要讨论了 Milestone 2 的文档与展示材料、项目仓库的开发方式，以及接下来例会大致的议程内容。

## 一、Milestone 2 文档及展示材料

组内确认了 Milestone 2 正式文档和展示稿的编写、排版安排。正式文档以项目的 Vision、Scope、Features 和 Feature Roadmap 为主，说明项目要解决的问题、计划完成的功能及开发进度；展示稿在这个基础上挑了课程重点要求的内容进行展示。

## 二、仓库开发方式与成员规范

会议向组员说明了 GitHub 仓库的代码开发与协作方式，并确认各自按照统一规范进行开发。以 main 分支作为稳定分支，每位成员在自己的独立分支上负责开发相应模块，开发成果通过 Commit 留下记录，再根据功能完成情况逐步整合。

各模块尽量保持清楚的职责和接口，优先完成可以单独运行和测试的部分；涉及公共数据结构或其他成员接口的调整需要提前沟通，在后续的会议上提出并和相关成员协调解决。对于已经完成并经过基本测试的功能，及时提交和同步，避免将大量未经联调的代码留到最后一次性合并。开发过程中还需保留相应的工作记录，方便后续整理项目过程材料。

## 三、后续会议的基本议程

经过几位组员确认确认，后续例会按以下顺序进行：

1. 汇报开发中遇到的问题：各成员简要说明目前的实现情况，重点提出运行报错、接口衔接、模块依赖或测试方面的阻碍。
2. 讨论并协调解决方案：对需要跨模块配合的问题进行讨论，明确调整办法、相关负责人及必要的后续沟通。
3. 确认整体进度和下一半周计划：对照项目时间安排检查当前进度，确定接下来半周各模块准备完成的工作和需要交接的内容。
