Date: 2026-11-03. This is a bounded preparation step. No real LoCoMo extraction, production Memory publication, full index or Gold evaluation occurred.

## High business contract

The API request ID for DeepSeek-V4.1-Flash-1017 is `deepseek-flash`. [Official Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode/) specifies `reasoning_effort="high"` plus `extra_body={"thinking":{"type":"enabled"}}` for Chat Completions. The adapter omits `temperature` in thinking mode because the provider ignores it. Disabled requests retain the prior explicit switch and temperature behavior. Only `message.content` reaches `LLMResponse.raw_output`; `reasoning_content` is neither returned by the adapter nor recorded. Numeric `completion_tokens_details.reasoning_tokens`, when provided, is retained inside validated token usage and cannot exceed total completion tokens. Empty final text, whitespace JSON, truncation and malformed usage fail closed.

The opt-in profile is `configs/models_high_pilot.yaml`: `model_id=deepseek-flash`, thinking enabled, effort high, extraction/QA output budget 2,048 tokens, timeout 90 s, zero retries, one concurrent request. `default_backend=mock` and `api_enabled_by_default=false` stay in place. Normal `load_settings()` still uses the offline profile; callers must explicitly pass `models_profile=...` and `create_runtime(..., backend="deepseek", api_enabled=True, api_key=...)` to use real service. The business model does not change Codex settings. Request fingerprints include `reasoning_effort`; Runtime settings and execution policy fingerprints include thinking/effort and an adapter version, so High and disabled calls cannot share cache identities. Historical Mock configurations with enabled thinking but no effort still load; real Adapter rejects them with `EFFORT_REQUIRED` before a request.

The isolated `scripts/stage_b0_high_smoke.py` requires `--live --confirm-low-cost` and has its own persistent TEMP ledger. Its two slots are exhausted. Each request was synthetic, non-streaming, capped at 2,048 generated tokens, with no SDK or Guarded retry. Both succeeded: text 35 input/11 completion/9 reasoning tokens (2.579 s); JSON 71 input/24 completion/11 reasoning tokens (2.5 s). Both had `finish_reason=stop`, one attempt, valid final content; no reasoning text was saved. Total 106 input + 35 completion tokens. Using [official peak cache-miss Flash rates](https://api-docs.deepseek.com/quick_start/pricing/), the upper estimate is USD 0.0000738; actual billing may differ.
