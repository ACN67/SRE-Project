## 已实现功能、写法与原理

| 功能 | 写法与原理 |
| --- | --- |
| 稳定错误码提示 | `web/status.py` 维护 IC-012 等错误码到固定中文文案的白名单；`known_error_code()` 仅读取异常 `.code`，不匹配异常文本。`app.py` 的 `report_error()` 展示对应说明、错误码和诊断号 |
| 敏感信息隔离 | 未知或格式不合法的错误码不回显；页面不显示原始异常消息，日志只记录异常类型和诊断号 |
| 加载失败后刷新 | 将样本列表读取移到侧栏刷新按钮创建之后，样本服务暂时失败时仍能重新初始化当前会话并重试 |
| 过期选择清理 | 初始化、样本列表或记忆读取失败后清除已选详情和来源；服务恢复后不会自动恢复旧引用 |
| 接入状态说明 | 非 synthetic 服务显示构建状态接口尚未接入，不将四个既有读取接口的结果冒充 BuildStatus |

页面区分未加载、加载失败、未构建、部分构建、构建失败、产物损坏或过期等已知异常，以及正常返回的空列表。这里显示的是服务明确报告的错误，不是 Web 根据数据猜测的构建状态。
