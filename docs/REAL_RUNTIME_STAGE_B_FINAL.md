## Failure accounting and privacy

The adapter parses numerical usage, cache hit/miss, model identity and finish reason **before** rejecting `length`, empty/invalid JSON or other incomplete responses. Reasoning text is never stored. Private budget rows contain fixed status/category, safe model ID, elapsed milliseconds, input bytes/estimate, actual prompt/completion/reasoning tokens, final tokens only when reasoning count exists, cache hit/miss when supplied, and finish reason. Completion already includes reasoning and is billed once. A complete cache breakdown uses peak cache-hit/miss rates; otherwise the estimator prices all input at the conservative miss rate. Missing usage stays unknown, never zero cost. Failure, timeout or uncertainty permanently consumes the reservation.

The paid runner resolves its budget root via the Windows Local AppData known folder, independent of caller `LOCALAPPDATA`, working directory or `--state-dir`. A separate authorization registry records the next attempt count **before** writing the attempt ledger. Missing ledger after marker, missing marker after ledger, interrupted write, mismatched approval/run or rolled-back count fail closed. Process and budget locks reject concurrent use. Local files are an operational audit boundary, **not cryptographic protection against an account holder deleting every copy**; total loss requires manual reconciliation, never automatic reuse. Old B-R4 ID `user-chat-20261103-pilot01` is consumed and its v1 approval fails the new v2/run-fingerprint gate.

Private state holds checkpoints, review queues, safe usage rows and eventual artifact/index. Do not copy dialogue, drafts, thought text, credentials, Gold, full Memory or vector data to Git or a public report.
